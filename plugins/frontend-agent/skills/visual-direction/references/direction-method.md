# Direction Method

For each direction describe:

- concept and emotional quality;
- target-user and task fit;
- information density and layout;
- type hierarchy and content voice;
- shape, color, surface, and depth;
- navigation and critical interaction;
- motion purpose and reduced-motion behavior;
- responsive/platform adaptation;
- accessibility and performance implications;
- implementation cost, maintenance, and risk.

Advanced graphics need a non-graphics fallback and a budget for CPU/GPU, memory, network, startup,
and input latency on low-power devices.
