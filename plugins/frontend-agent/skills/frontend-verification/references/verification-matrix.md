# Frontend Verification Matrix

Select applicable rows:

- platforms, browsers, devices, orientation, viewport, zoom, and content scaling;
- anonymous/authenticated roles and permission states;
- keyboard, focus trap/restore, skip navigation, names, roles, states, live regions;
- contrast, forced colors, dark/light themes, high contrast, and reduced motion;
- loading, empty, long content, localization, RTL, partial data, error, offline, and retry;
- pointer, touch, coarse input, screen reader, and platform accessibility API;
- bundle/startup/render/input/network budgets and low-power fallback;
- screenshots, animations, canvas/WebGL fallback, and visual regressions.

For every finding record environment, steps, expected, actual, evidence, severity, and confidence.
