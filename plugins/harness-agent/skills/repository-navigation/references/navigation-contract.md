# Navigation Contract

A good navigator answers:

- what the repository contains;
- which source is canonical for product, architecture, APIs, schemas, operations, and testing;
- which commands build, test, validate, and deploy;
- where component ownership and scoped instructions live;
- which documents are proposed, accepted, implemented, validated, superseded, or historical;
- what an agent should read for a task and what it can skip.

Keep summaries to one sentence per destination. Link to content instead of duplicating it.
