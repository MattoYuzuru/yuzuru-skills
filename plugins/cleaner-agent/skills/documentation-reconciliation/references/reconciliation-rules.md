# Reconciliation rules

Prefer the source with explicit ownership, accepted status, current requirements, verified behavior,
and supporting decisions—not merely the newest timestamp.

When replacing a canonical artifact:

- update links and navigator entries;
- preserve or link rationale;
- mark superseded status and successor where the artifact model supports it;
- verify embedded commands, filenames, configuration, diagrams, and examples;
- leave unresolved disagreements visible.

Do not rewrite incident evidence to match the current system. Add resolution context instead.
