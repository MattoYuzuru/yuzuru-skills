# Research Funnel

## Query sequence

1. Underlying job and broad category.
2. Direct products using regional and local-language terms.
3. Open-source packages, recent releases, issue activity, and license.
4. Adjacent workflows that remove the need for a new product.
5. Region-specific payments, device access, infrastructure, distribution, privacy, and regulation.
6. Current user complaints from support forums, issue trackers, reviews, and communities.
7. Technical feasibility from official platform docs, maintained source, and credible benchmarks.
8. Failure stories and discontinued products, separating fact from post-hoc explanation.

## Coverage dimensions

For each material alternative capture audience, job fit, deployment model, pricing/access,
language, device and literacy assumptions, data handling, maintenance health, integration limits,
and the reason a user would still choose the proposed idea.

## Stop rule

Stop when:

- each decisive unknown has evidence or is explicitly unknowable;
- direct, open-source, regional, and adjacent categories have been sampled;
- new sources repeat existing conclusions;
- the remaining uncertainty is better resolved by a prototype or real user test.
