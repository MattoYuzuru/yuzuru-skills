# Independent Review Contract

Review the requested behavior and diff for:

- correctness and boundary cases;
- architecture and API compatibility;
- persistence, migrations, and data integrity;
- concurrency, ordering, idempotency, cancellation, and resource lifecycle;
- authentication, authorization, input boundaries, and sensitive logging;
- errors, retries, timeout, observability, and operational behavior;
- performance on plausible workload;
- regression and test gaps;
- unnecessary abstraction and unrelated churn;
- documentation and completion evidence.

Each finding needs exact location, evidence, impact, confidence, and a validation or regression test.
