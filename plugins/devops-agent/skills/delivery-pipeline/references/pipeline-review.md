# Pipeline Review

Review:

- triggers, concurrency, cancellation, branch and path filters;
- fork and untrusted pull-request behavior;
- job permissions, runner trust, privileged containers, and secret availability;
- dependency locks, cache keys, restore fallback, poisoning, and invalidation;
- test/lint/build/security/package stages and diagnosable failure output;
- artifact identity, provenance, signing, retention, and promotion;
- environment approvals, deployment locks, migration ordering, smoke checks, and rollback;
- scheduled-job timezones, overlap, retry, and missed-run behavior.

Validate against current official host documentation; workflow schemas and action versions change.
