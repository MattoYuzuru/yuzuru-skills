# Operations Baseline

Select only the areas relevant to the current task:

- reproducible developer bootstrap and environment parity;
- CI build, lint, test, security, packaging, caching, artifacts, retention, and diagnostics;
- container non-root user, minimal runtime, health, graceful shutdown, and provenance;
- configuration validation, secret references, dependency health, and certificate expiry;
- deployment locks, migration sequencing, connection draining, smoke tests, and rollback;
- backups, restore evidence, disaster recovery, disk/inode thresholds, and retention;
- logs, metrics, traces, correlation, deployment markers, alerts, SLOs, and runbooks;
- queue workers, cron reliability, autoscaling signals, capacity thresholds, and cost;
- preview environments, blue-green, canary, rolling, and feature-flagged release;
- IaC drift, least privilege, supply chain, SBOMs, and artifact signing where justified.

Do not add every item to every repository. Each addition needs an objective, owner, and validation.
