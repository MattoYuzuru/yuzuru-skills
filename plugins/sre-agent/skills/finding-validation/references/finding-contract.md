# Finding Contract

A confirmed finding includes:

- stable ID, classification, severity, and confidence;
- affected requirement and component/location;
- preconditions and isolated reproduction;
- expected and actual result;
- logs, data, screenshots, traces, test output, or code/config evidence;
- user/system impact and scope;
- correction direction without pretending implementation is trivial;
- regression-test recommendation;
- cleanup and environment notes.

If any decisive element is absent, use probable, risk, missing-evidence, or unverified status.
